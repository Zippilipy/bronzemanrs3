# Bronzeman

This plugin introduces a custom way to play the game, if you've heard it from OSRS then you'll know what it's about, but if you don't, think of bronzeman as an in-between of the regular player experience and ironman accounts.

Bronzeman restricts access to the Grand Exchange until you have unlocked the item you are trying to buy. It restricts you from being able to pick up items that are not yours. Trading is disabled for all items except bonds, with the purpose of being able to give membership.

## What counts for an unlock?

Any item that is obtained through regular means is an unlock, this means skilling, pvming, buying from shops and pking.

This means you can unlock potions that you don't have the skilling requirement to make if you obtain them some other way.

Any item that you already have obtained, in your inventory or bank, gets automatically added when starting the plugin.
